# Resume Screening and Job Recommendation System

This project is an AI-powered Resume Screening and Job Recommendation System developed using Python, Machine Learning, Natural Language Processing (NLP), and Streamlit.

The system analyzes a candidate's skills from a resume, compares them with job requirements using TF-IDF Vectorization and Cosine Similarity, and recommends the most suitable job roles with matching scores.

## Features
- Resume skill analysis
- Job recommendation system
- Match score calculation
- Interactive Streamlit web application
- Data visualization of recommendation results

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Machine Learning Techniques
- TF-IDF Vectorization
- Cosine Similarity
- Natural Language Processing (NLP)

## Project Outcome
The system helps automate resume screening and suggests relevant job opportunities based on a candidate's skills and qualifications.
